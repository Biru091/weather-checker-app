# Weather Dashboard

## Overview
A responsive weather application built using React and Vite that provides real-time weather information using the OpenWeather API. Users can search for any city and view current temperature, weather conditions, and location details.

---

## Features
- Search weather by city name  
- Displays current temperature  
- Shows weather condition and location  
- Dynamic weather icons based on API response  
- Default weather load on application start  
- Responsive UI design  

---

## Tech Stack
- React  
- Vite  
- Axios  
- OpenWeather API  
- JavaScript  
- CSS
